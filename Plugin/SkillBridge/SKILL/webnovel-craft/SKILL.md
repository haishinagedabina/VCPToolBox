# 中文网文章节工艺

## Overview

网文和传统文学的评价函数不同。读者按章追读、随时可以关掉，所以**单章必须自带回报，且结尾必须让人想点下一章**。文学性再高，如果一章读完没有获得感、结尾平滑收束，追读就断了。

本技能是写单章时的工艺手册。结构层面的事（弧型、伏笔规划）见 `story-architecture`；台账字段格式见 `novel-ledger`。

## 一、爽感密度

### 1.1 爽点类型

| 类型 | 内核 | 典型场景 |
|---|---|---|
| 打脸 | 先被轻视，后用结果反驳 | 被嘲讽资质低下，随后展示越级战力 |
| 反转 | 读者与角色的预期同时被推翻 | 以为是救兵，其实是幕后黑手 |
| 实力揭示 | 已积累的底牌首次公开 | 隐藏功法/身份在关键时刻亮出 |
| 情感回报 | 长期投入的关系得到确认 | 一直冷淡的师长终于认可 |
| 信息差揭穿 | 读者已知的信息终于捅到角色面前 | 主角早知阴谋，当众拆穿 |

### 1.2 密度与投放位置

- **单章 1 个主爽点**。两个以上会互相稀释，读者记不住哪个是重点。
- **主爽点投放在全章 60–80% 处**，不要开篇就给。前 60% 是压力累积段——压力越足，释放越爽。
- 爽点前置是新手最常犯的错：开篇即高潮，之后全章无处可去，读者读到中段就走。
- 可以有次级小回报（一句漂亮的还击、一个小信息揭示）散布在前段维持注意力，但不占用主爽点的位置。

### 1.3 爽感的前提是代价

无代价的胜利不爽，只是流程。主角赢之前必须先真实地付出或失去某样东西——消耗底牌、受伤、暴露秘密、失去一个盟友。读者感知到的爽感强度，正比于他之前感知到的压力。

## 二、章末钩子

### 2.1 类型库

**悬念型** —— 抛出一个未解答的问题。
- 陌生人报出主角早已死去的师父的名字。
- 密室里的尸体穿着和主角一模一样的衣服。

**危机型** —— 让威胁在最后一刻降临。
- 刚脱险，抬头看见更强的敌人堵在唯一出口。
- 收到消息：家族已在三天前被围。

**信息揭示型** —— 在结尾丢出一个改变读者理解的事实。
- 追杀他的人，腰牌上刻着他自己宗门的徽记。

**情感悬置型** —— 让一段关系停在未决状态。
- 她转身走了，什么都没说。他这才发现桌上留下了那枚玉佩。

**反转预告型** —— 暗示下一章将发生颠覆。
- 他以为自己赢了。而那个人在暗处笑了一下，收起了三枚未曾使用的令牌。

### 2.2 去重铁律

**连续章节不得使用同类型钩子。** 连续三章都用危机型，读者会识破套路，钩子失效并且显得廉价。写章末钩子前先看上一章用的是哪型，换一个。

节拍表里必须显式记录本章钩子类型，这既是给审稿核对的依据，也是给下一章作者的去重参考。

### 2.3 钩子的位置

钩子是**最后一到三段**的事，不是最后一句。给它一点铺垫空间，突兀的一句反转读者反应不过来。

写完钩子就停笔。**不要在钩子后面加解释、加总结、加抒情收束**——那会把悬置感抹平，这是最常见的钩子失效原因。

## 三、节奏张弛

### 3.1 章节类型交替

| 类型 | 作用 | 后面适合接 |
|---|---|---|
| 爆发 | 释放累积的压力，主爽点密集 | 铺垫 / 日常过渡 |
| 推进 | 主线往前走，中等强度 | 任意 |
| 铺垫 | 累积压力、埋设伏笔 | 爆发 / 转折 |
| 转折 | 改变局面走向 | 推进 |
| 日常过渡 | 关系经营、喘息 | 铺垫 / 推进 |

**爆发章后面不要紧接爆发章。** 连续高强度会让读者钝化，第二次爆发的效果远低于第一次。让他先喘一口气，压力重新积起来再打。

反过来，**连续两章以上的铺垫或日常是追读杀手**。铺垫章内部也必须有小回报和有力的钩子。

### 3.2 单章内的张弛曲线

一个可靠的默认形状：

```
开场（切入场景，接上一章钩子）
  → 压力上升（问题变复杂 / 对手更强 / 时间更紧）
    → 局部挫败（让读者真的担心）
      → 主爽点（60-80% 处，释放）
        → 章末钩子（新问题）
```

不要每章都严格套这个形状——连续二十章同一曲线，读者会感到机械。铺垫章可以省掉主爽点，用一个更强的钩子补偿。

### 3.3 承接上一章钩子

**本章开场必须回应上一章的钩子**，而且要在前三段内。上一章结尾把人吊在悬崖上，这一章开头不能先写他三天前吃了什么。

回应不等于立刻解决。可以把危机进一步恶化，可以给出部分答案引出更大的问题——但必须让读者感到"我关心的那件事正在被处理"。

## 四、信息投放速度

### 4.1 按需披露

设定不得一次倾倒。**读者只在需要理解当前情节时，才想知道那条设定。**

反例：主角刚踏入宗门，作者花两千字介绍九大境界、七十二派系谱、三千年前的大战。读者记不住，也不关心，直接跳读。

正例：主角要突破第二境时，才解释第二境是什么、难在哪、代价是什么。这时这条信息是他的燃眉之急，读者会认真读。

### 4.2 单章新设定上限

**单章引入不超过 2 条新设定**（新境界、新势力、新规则、新物品体系各算一条）。超过就是设定倾倒。

需要大量世界观铺陈时，把它拆散到多章，每章挂在一个具体的情节需求上。

### 4.3 让设定通过冲突出场

**不要用旁白解释设定，用冲突展示设定。**

- 弱："炼气期无法承受灵脉冲击。"
- 强：他咬牙引第二道灵脉入体，经脉当即爆开一线血口——炼气期的身体，接不住这个。

后者同时给出了设定、代价和紧张感。

## 五、视角控制

### 5.1 默认用深度第三人称限知视角

- 只写视角角色能感知的：他看到的、听到的、想到的。
- 不写他不可能知道的：其他人的内心、他视线外发生的事。
- 这不是文体洁癖——限知视角是**信息差的产生装置**，而信息差是网文最重要的剧情引擎。全知视角会把悬念提前泄干。

### 5.2 认知边界必须查台账

写作前读 `state/cognition.md`，确认视角角色的 `does_not_know` 清单。

**如果角色的行动依赖了他 `does_not_know` 里的信息，就是崩坏。** 这类错误读者极其敏感（"他怎么知道的？"），而且一旦发生就破坏整条信息差线索。

同样要利用 `reader_knows_but_character_does_not`——读者知道而角色不知道的事，是紧张感的免费来源（读者眼看他走进陷阱）。

### 5.3 视角不在场景内跳跃

一个场景一个视角。要换视角，用场景分隔（空行或分节），不要在同一段里从主角脑子里跳到对手脑子里。

## 六、对话与心理描写

### 6.1 对话必须有区分度

**不同角色的说话方式必须不同。** 这是 AI 写作最容易暴露的地方——所有人用同一套句式、同一个词汇量、同一个礼貌程度说话。

给每个重要角色至少两个稳定的语言标记：

- 句子长度习惯（有人只说短句）
- 用不用敬语、称谓怎么变
- 有没有口头禅或回避的话题
- 情绪激动时是变吵还是变安静

写完一段多人对话，做这个检查：**把说话人标签全部遮住，还能分辨谁是谁吗？** 不能，就是没写好。

### 6.2 不要用心理描写代替行动

- 弱：他感到非常愤怒，心里想着一定要报复回去。
- 强：他把那枚碎裂的玉佩收进袖中，指节压得发白。转身时，脸上已经没有表情了。

心理活动写多了会让节奏变黏。愤怒、恐惧、决心这类强情绪，优先用动作、生理反应、对话里的失态来呈现。

心理描写的正当用途是**呈现判断与权衡**（他在两个选择之间算计），而不是复述已经从行动里看得出的情绪。

## 七、反面清单

写完自查，这些是中文网文里的高频雷点：

**语言层**

- 滥用模糊虚词：「某种程度上」「在一定意义上」「不知为何」「仿佛」堆叠。虚词多说明作者自己没想清楚。
- 副词代替动词：「非常快地跑」不如「窜」。
- 空泛抒情：「他的内心久久无法平静」——什么都没说。
- 排比式煽情：连续三个「他想起了……」。
- 用力过猛的比喻，一段里超过一个就显得刻意。

**人物层**

- 全员同一说话方式（见 6.1）。
- 配角只在需要他时才有反应，其余时间像不存在。同场景的角色都要有存在感。
- 主角全程正确，从不误判。会犯错才有人味，也才有翻盘的空间。
- 反派愚蠢化——为了让主角赢而降智，会让爽感变廉价。

**结构层**

- 爽点前置（见 1.2）。
- 设定倾倒（见 4.2）。
- 钩子后加收束解释（见 2.3）。
- 连续同型钩子（见 2.2）。
- 章节开头不接上一章钩子（见 3.3）。
- 用巧合解决危机。危机的解法必须来自已经建立过的能力、物品或关系——否则读者感觉被骗。

**一致性层**

- 角色知道了不该知道的（见 5.2）。
- 实力/境界跳跃而无交代。
- 前文提过的物品、承诺、伤势后文凭空消失。

## 八、收工前的自查清单

- [ ] 开场前三段是否回应了上一章的钩子？
- [ ] 主爽点是否在 60–80% 处，且之前有足够的压力累积和代价？
- [ ] 章末钩子类型是否与上一章不同？钩子后面有没有多余的解释？
- [ ] 本章新增设定是否 ≤ 2 条，且每条都挂在具体情节需求上？
- [ ] 遮住说话人标签，多人对话还分得清谁是谁吗？
- [ ] 对照 `state/cognition.md`：视角角色的行动有没有依赖他不该知道的信息？
- [ ] 节拍表里的每一条推进项是否都真的落实了？
- [ ] 通读一遍第七节反面清单，逐条排查。
