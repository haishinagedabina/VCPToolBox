# Quill 微信平台限制速查

源自 wewrite/references/wechat-constraints.md, 精华压缩版。**大多数限制已由 WeWriteRender 的 converter 自动处理**, 本文件只列出 Quill 需要主动避坑的部分。

## 一、字数与图片硬约束

| 项目 | 官方上限 | 推荐值 | 触发后果 |
|------|---------|--------|---------|
| 单篇文章字数 | 20,000 字 | 1,500-2,500 字 | 超过推荐范围会让读者翻不动 |
| 单篇图片数量 | 10 张 (视频算 1 张) | 4-8 张 | 超 10 张接口报错, draft/add 失败 |
| 单图大小 | 5MB | < 1MB | 大图会影响打开速度 |
| 标题长度 | 64 字节 | 5-64 字节 (≈ 20-28 中文字) | 超长会被截断 |
| 摘要长度 | 120 字节 | ≤ 40 中文字 | 超长被截断, 影响微信卡片预览 |

**Quill 自检责任**: 调 WeWritePublish 前必须确认字数 ≥ 1,200, 图片 ≤ 10, 标题字节数符合区间。

## 二、不支持的功能 (直接放弃)

- ❌ **JavaScript** — 完全禁用, 没有交互能力
- ❌ **外部 CSS** (`<link rel=stylesheet>` / `<style>` 块) — 只支持内联 `style=""`
- ❌ **本地图片** (`file://` / 相对路径) — 必须上传到微信服务器
- ❌ **自定义字体** (`@font-face`) — 只能用系统字体栈
- ❌ **CSS 动画** (`animation` / `@keyframes` / `transition`)
- ❌ **3D 变换** (`transform: rotate/scale/translate`)
- ❌ **粘性定位** (`position: fixed/sticky`)
- ❌ **滤镜** (`filter: blur()` / `backdrop-filter`)
- ❌ **非腾讯视频/微信音频素材库** — `<video>` / `<audio>` 标签都不行
- ⚠️ **外部链接** — 已认证公众号支持但需审核; 未认证号不支持 (大斌的AI小栈是个人订阅号, 实名认证已通过, 链接可用但要少而精)

## 三、wewrite converter 自动修复 (无需 Quill 干预)

以下限制由 WeWriteRender 自动处理, 你**不要在 markdown 里手动绕开**:

| 平台限制 | converter 自动修复 |
|---------|-------------------|
| 外链被屏蔽 | 自动转为上标编号脚注 + 文末参考链接列表 |
| 中英文混排无间距 | CJK-Latin 边界自动插入空格 |
| 加粗文本后中文标点渲染异常 | 标点自动移到 `</strong>` 标签外 |
| 原生 `<ul>/<ol>` 列表渲染不稳定 | 自动转为 `<section>` + 样式化 bullet/number |
| 暗黑模式颜色反转错误 | 自动注入 `data-darkmode-color/bgcolor` 属性 |
| `<style>` 标签被剥离 | 所有 CSS 以内联 `style` 属性注入 |
| 表格在移动端超屏 | 自动加 `overflow-x: auto`, 但**建议表格列数 ≤ 4** |
| 代码块格式丢失 | 用 `<pre>` + `<code>` + 内联 Pygments 高亮 |

所以你在 Markdown 里**就用标准 Markdown 语法**: `**加粗**`、`[链接](url)`、`![图片](path)`、` ```python 代码 ``` `, converter 会自动处理成微信兼容版本。

## 四、容器语法 (wewrite 扩展, 微信友好)

Quill 可在 Markdown 中使用以下扩展容器, converter 会渲染成对应样式块:

```
:::dialogue
A: 你为什么要做这个项目?
B: 因为不爽。
A: 就这? 没了?
B: 没了。
:::

:::timeline
2024-01: 立项, 团队 3 人
2024-06: 第一个 demo, 用户增长到 500
2024-12: 砍掉一半功能, 用户增长到 3 万
:::

:::callout type=warning
这个方案有风险: 一旦数据丢失无法恢复, 务必先备份。
:::

:::quote source="《精益创业》Eric Ries"
真正的进步不是看你做了多少功能, 而是看你验证了多少假设。
:::
```

四种容器类型:
- `:::dialogue` — 对话体, 适合故事型/纯观点型框架
- `:::timeline` — 时间线, 适合复盘型/故事型框架
- `:::callout type=info|warning|success|danger` — 强调框, 突出关键信息
- `:::quote source="..."` — 引言块, 引用他人观点

## 五、发布前最后自检 (调 WeWritePublish 前必读)

- [ ] **正文字数 ≥ 1,200** (微信不收录过短文章)
- [ ] **正文字数 ≤ 3,000** (推荐区间 1,500-2,500, 超过读完率骤降)
- [ ] **标题 5-64 字节** (即 ≈ 5-28 中文字, 含标点)
- [ ] **摘要 ≤ 120 字节** (即 ≈ 40 中文字; 不传时由 converter 自动生成)
- [ ] **图片 ≤ 10 张** (含封面)
- [ ] **封面 cover_image_url 已就绪** (走过完整兜底链: 生图工具 → 本地兜底图)
- [ ] **外部链接 ≤ 3 条** (即使认证号, 多了影响阅读)
- [ ] **表格列数 ≤ 4 列** (移动端友好)
- [ ] **代码块 < 30 行** (太长建议截图)
- [ ] **要求 6 位 requireAdmin 验证码** (用户提供, 不要自动用 `{{USER_AUTH_CODE}}`)

任一不满足 → 停下来修复, 不要硬推。

## 六、常见错误码速查

| errcode | 含义 | 处理 |
|---------|------|------|
| 0 | 成功 | - |
| 40007 | invalid media_id | 封面没传或 thumb 上传失败, 检查 cover 兜底链 |
| 40164 | invalid ip | IP 不在白名单, 让用户加 `14.127.45.2` 到微信后台 |
| 40097 | invalid args | 参数错 (常见: 标题/摘要超长、count 区间错误) |
| 41001 | missing access_token | token 失效, force_refresh 重新签发 |
| 45009 | reach max api daily quota | 调用频次超限 (订阅号每分钟 100 次), 等一会儿重试 |
| 48001 | api unauthorized | 接口未授权 (订阅号未认证或缺少能力), 报告给用户 |
| 53004 | 违规 | 内容触发审核, 检查标题/正文是否含敏感词 |

## 七、个人订阅号的能力边界 (大斌的AI小栈)

经验证, 当前账号 (`account_type=1` 实名个人订阅号) 已开放:
- ✅ `draft/add` 草稿箱 API (Quill 的核心通道)
- ✅ `material/add_material` 永久素材上传 (封面 thumb)
- ✅ `media/uploadimg` 文章内图片上传 (正文图片)
- ✅ `account/getaccountbasicinfo` 账号信息

未开放 (即使写了也会 48001):
- ❌ `menu/get` 自定义菜单
- ❌ 模板消息接口
- ❌ 客服消息接口

群发限制:
- 订阅号每天最多 1 次群发
- 群发后无法修改文章内容 (只能改 24 小时内的错别字)
- **Quill 默认只发草稿, 不直接群发** — 群发由用户在后台手动确认
