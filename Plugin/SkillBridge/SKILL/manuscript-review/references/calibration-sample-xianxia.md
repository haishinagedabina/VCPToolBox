# 第一章 逐出

青石阶上还留着雨水。

林越跪在那里，膝盖下的石缝渗出凉意，一直爬到腰。他已经跪了两个时辰。执法堂的门开着，里面没有人说话。

"灵根测过三次了。"孙执事终于开口，声音不高，"下品杂灵根，三十年不入炼气三层。宗门每年供给三千弟子，供不起一个走不到头的。"

林越没抬头。他知道该说什么，那些话他在心里排过一夜——师父临终托付、他答应过守着后山那片药田、他还差半年就能引气过第二道经脉。可这些话在这里一句都不管用。

"腰牌交上来。"

他解下腰牌。铜牌边缘被摸得发亮，那是十二年。

"还有一件事。"孙执事看着他，"你师父留下的东西，按规矩归宗门。"

林越的手停住了。

"《青枝录》不是宗门功法。"他说。这是他今天第一句话。

"你师父是宗门的人。"

"她被除名十九年了。"

堂里安静了一下。孙执事身后有个弟子笑了一声，很轻，但林越听见了。他慢慢站起来，膝盖不太听话，晃了半步才稳住。他把腰牌放在阶上，没有递过去。

"东西我带走。人我也带走。"

"你带走什么人?"

林越没答。他转身下阶，走了七步,才有人反应过来要拦。孙执事抬手止住了。
"不必。"孙执事说,"下品杂灵根,出了这道门,活不过三年。"

林越听见了。他没有回头，也没有加快脚步。

雨又开始下。他一路走到山门外，走到再看不见那块牌匾的地方，才停下来。然后他从怀里取出一样东西——不是《青枝录》。那是半枚玉佩，断口很新。

师父死的那天，另外半枚不在她身上。

他知道在谁身上。

"三年。"他说。

雨水顺着断口流下来，冲开了玉佩上一层薄薄的、暗红色的东西。
