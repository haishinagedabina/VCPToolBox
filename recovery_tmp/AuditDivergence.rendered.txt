## ② 标尺A — 书中原文判定标准（第三章3、4）

> **铁律**：以下仅引用《短线操盘实战技法》第三章3、4节原文；禁止写入书中没有的推断、外推或算法术语（如"底部反转"）。

底背离（第三章3，仅做底背离，目的是找入场点）:
- **定义（原文）**：在下跌趋势中，当股价**创新低**时，黄白线却没有创新低，即是底背离…卖盘动能衰竭、买盘动能积聚，向上的动能正在不断积聚，后市上涨的概率比较大。
- **黄白线**：MACD 的 DIF/DEA 两线（非红绿柱）。
- **六种形态**（表3-1；A=前低点，B=后低点；a/b=对应黄白线低点）：
  - 股价底部**抬升式**（B>A）：b<a / b=a / b>a
  - 股价底部**下降式**（B<A）：b>a / b=a / b<a
  - 股价底部**平行式**（B=A）：b>a / b<a
- **书对抬升式的明示（图3-6节）**：股价低点抬升式底背离…上涨**快速、强劲**…**多为短线上涨趋势、很少长线**…**准确率比较高，很适合短线操作**。
- **书末句（"底背离"节末）**：以上六种底背离形态，**运用方法一样，效果也没有区别**——书**未排除任一形态**。
- **形态属性（原文）**：底背离**不是具体时点，而是一段时间内出现的形态**；常有二次/多次背离；须**结合技术手段寻找具体入场点**。

底背离双突破买入法（第三章4）:
1. 发现新低点；2. 确认底背离；3. 新低后找上涨回抽形成的**近期高点**（书要求：该近期高点须距新低点不远）；
4. 任意远期高点连近期高点画**下降趋势线**（画法可随意）；
5. 以**近期高点**画**水平阻力线**（支点必须是近期高点，不可随意）。
- 逻辑：底背离=卖方衰竭；**趋势线+阻力线双突破**=买方动能强劲确认。
- 趋势线之上、阻力线之下的临界区域用于寻找初期止损点。

## ③ 标尺B — DSA 算法实现（strategies/bottom_divergence_double_breakout.yaml）

- 检测器 `BottomDivergenceBreakoutDetector`：在 swing lows 找 A/B 低点对（10~60 bars，中间有反弹高点 H），匹配 DIF/DEA 局部最低值。
- 三态分类后**仅保留真正底部反转型**：price_down_macd_up / price_down_macd_flat / price_flat_macd_up；price_flat_macd_down 与 price_up_* 已排除。
- 上下文门控：底部反转型需前置下跌验证（MA5<MA20 或斜率为负）。
- 双突破：水平阻力线=反弹高点 H；下降趋势线=结构 swing highs 拟合；收盘同时突破两者。
- `bottom_divergence_actionable_entry==true`：刚完成双突破，或 3 根 K 内仍在确认价上方且偏离 ≤10%。
- 同步性：两突破在 3 bars 内 → confirmed(sync_breakout=True)；超 3 bars → late_or_weak。
- 筛选硬门槛：`bottom_divergence_double_breakout==true` 且 `actionable_entry==true` 且 `confirmation_days<=3`。
- 评分：signal_strength(35) + entry_timing_score(25) + volume_ratio(20) + trend_score(20)。
- 关键因子字段：`bottom_divergence_state`(rejected/divergence_only/structure_ready/confirmed/late_or_weak)、`bottom_divergence_pattern_code`(六形态)、`bottom_divergence_signal_strength`、`sync_breakout`、`breakout_freshness_bars`、`price_low_a/b`、`rebound_high`、`horizontal_resistance`。

## ④ 复核协议（逐条对照 + 偏差分级）

**先逐项核对 checklist，再下结论；结论必须与 checklist 一致：**
1. 形态归类：`pattern_code` 是否落在表3-1 六种形态之一？书末句明示六形态**运用方法一样、效果没有区别、未排除任一形态**；书对抬升式另明示**准确率较高、很适合短线操作**。算法若排除 price_up_* 或 price_flat_macd_down，是否构成与书的偏差？若属工程取舍，依据何在？**不得用书中没有的口径（如"底部反转"）替算法排除背书。**
2. 背离本质：A/B 与对应黄白线低点关系是否符合表3-1 三态组合？定义段写"股价创新低"，而抬升式 B>A 未必创新低——算法/证据是否忠实处理这一书内张力？
3. 双突破：是否**同时**突破趋势线与阻力线？阻力线支点是否为"新低后上涨回抽形成的近期高点"（书要求该高点**距新低点不远**，不可随意）？
4. 入场时效：`actionable_entry`/`confirmation_days<=3` 是否与书"形态非时点、须结合技术找具体入场点"一致？
5. 同步窗口：3 bars 的 sync 判定有无书面依据？是否过严/过松？

**偏差分级 rubric（每条结论必须引用因子字段=值）：**
- 致命：算法选股逻辑与书相反（如把顶背离/强势回撤当底背离选入）。
- 重要：阈值/形态判定偏离书意（如阻力线支点取错、同步窗口与书冲突）。
- 轻微：命名/措辞不符，但逻辑等价。
- 无偏差：忠实实现。

**Abstain**：若关键因子字段缺失，对应条目输出"无法判定 + 缺失字段名"，不得猜测。
