# 题材 preset · 仙侠 / 玄幻修真

用法：新建一本书时，把本文的内容按需拷进该书的 `world.md`（世界观、铁律）与 `style.md`（语体、黑名单），之后与本 preset 解耦，各书自由演化。

**这是起手模板不是标准答案。** 拷过去之后应当按本书设定改造——境界名、势力名都可以换，改造过的才有辨识度。原样照抄会写出满街都是的通货。

---

## 一、境界体系骨架

一个够用的九境框架（可裁剪、可改名）：

| 阶段 | 境界 | 核心特征 | 寿元 |
|---|---|---|---|
| 凡阶 | 炼气 | 引气入体，开始脱离凡人 | 百二十年 |
| | 筑基 | 筑成道基，可御物飞行 | 二百年 |
| | 金丹 | 凝气成丹，一方豪强 | 五百年 |
| 地阶 | 元婴 | 神魂具形，可夺舍重生 | 千年 |
| | 化神 | 神通显化，一域之尊 | 两千年 |
| | 炼虚 | 借虚御实，跨界而行 | 五千年 |
| 天阶 | 合体 | 法体交融，一击破山 | 万年 |
| | 大乘 | 半步登仙 | 数万年 |
| | 渡劫 | 迎天劫，成则飞升 | — |

设计要点：

- **境界数量宁少勿多。** 中篇（20–50 章）实际只会用到前三到四境。境界表列九个而只写到金丹，是正常的——留白比写满好。
- **每境要有可感知的能力跃迁**，不能只是数值变大。飞行、神魂离体、跨界，这些是读者能记住的分水岭。
- **每境内分前期/中期/后期/圆满**，给渐进成长留出空间，避免每次突破都是大事件。

## 二、修炼资源

资源必须**有来源、有稀缺性、有代价**。凭空出现的资源会让爽感变廉价。

| 类型 | 例 | 稀缺性来源 |
|---|---|---|
| 灵气环境 | 灵脉、洞天、灵田 | 被大势力占据，需要争夺 |
| 消耗品 | 丹药、灵石、符箓 | 需要材料 + 炼制者 |
| 传承 | 功法、秘典、道统 | 有主，或有获取门槛 |
| 器物 | 法器、本命物 | 需要炼制或夺取，且有认主限制 |
| 机缘 | 遗府、秘境、传功 | 一次性，且通常有争夺者 |

**代价机制**：速成必有反噬。透支灵脉伤经脉，强行突破留下道基裂痕，夺舍会残留他人神念。有代价的力量才有张力。

## 三、势力类型

- **宗门** —— 有传承、有山门、有等级序列。最常用的主角出身与初期舞台。
- **世家** —— 血脉传承，重出身，天然与"寒门崛起"叙事对立。
- **王朝 / 王庭** —— 凡俗政权，与修真界有默契或冲突。
- **散修联盟 / 坊市** —— 交易与信息集散地，剧情枢纽。
- **邪修 / 魔道** —— 反派池，但**不要写成纯粹的恶**。魔道要有自己的道理（"顺应本心""强者即正义"），才有对话空间。

## 四、时代事实包

该题材约定俗成的常识，读者默认已知，写作时不必解释，但必须自洽：

- 修士寿元远超凡人，因此时间尺度以数十年为单位是常态。
- 高阶修士神识可扫察方圆数里，藏身需要专门手段。
- 传音、传讯符是常规通信方式，但有距离和被截获的限制。
- 储物袋 / 纳戒是常规装备，容量与阶位相关。
- 越阶战斗极难，但可用底牌、地利、阵法、消耗品弥补。
- 灵根 / 资质决定修炼速度，但并非绝对上限——这是"废材流"的立足点。
- 契约、道誓有约束力，违誓有实质后果。
- 宗门大比、秘境开启、拍卖会是常见的剧情容器。

## 五、语体与风格

### 5.1 语体

**七分白话，三分古雅。** 现代白话为骨（保证阅读流畅），文言词汇为饰（保证题材氛围）。

- 用「不曾」「莫要」「何故」「须得」这类半文词汇，但不要整句文言。
- 数字用「三」「十二」而非「3」「12」。
- 长度单位用「丈」「里」「尺」，时间用「一炷香」「三日」「半年」。

### 5.2 称谓体系

称谓是修真世界的等级具象化，用错会立刻出戏：

- 对师长：师父、师尊、师伯、师叔
- 同门：师兄、师姐、师弟、师妹（严格按入门先后，不按年龄）
- 对陌生修士：道友（平辈）、前辈（高阶）、道兄
- 自称：晚辈、在下、贫道（道门）、小僧（佛门）
- 对宗门首脑：掌门、宗主、峰主

**称谓的变化本身是剧情信号**。从「道友」变「前辈」是示弱或认输；从「师兄」变全名是关系破裂。用好这一层，能省掉大段解释。

### 5.3 禁用风格黑名单

以下写法会让仙侠文立刻显得外行或出戏：

- **现代词汇混入**：「能量」「基因」「概率」「系统」「数据」「心理压力」「经济」。要写类似概念，用题材内的说法（灵气 / 血脉 / 天机 / 心境）。
- **现代口语**：「搞定」「没问题」「拜拜」「我服了」「牛」。
- **理论化叙述**：用现代科学框架解释修炼原理，会把神秘感抽干。
- **数值化战斗**：「战力提升了三成」这类量化表述。用感知描写替代：他这一掌下去，脚下青石先裂了三寸。
- **称谓混乱**：对同一人在同一场景里换着叫。
- **境界名滥用**：让低阶角色随口谈论渡劫、飞升。信息应当分层——低阶修士对高阶只有传说级的模糊认知。
- **翻译腔**：「他是如此的强大，以至于……」「不得不说，这是一个……」。

## 六、题材铁律（自洽约束）

违反这些会被读者当作硬伤，必须在 `world.md` 里明确并逐章遵守：

1. **境界不可跳跃。** 突破必须有过程、有条件、有代价。可以快，不能凭空。
2. **资源必有来源。** 主角手里的每一样东西，读者都应该记得他是怎么得到的。
3. **越阶不可无因。** 低阶战胜高阶必须有可解释的凭借（底牌、阵法、地利、对方轻敌 + 一次性消耗品），且凭借要事先建立过。
4. **寿元与时间尺度一致。** 提到某人闭关三十年，就不能同时把他写成少年心性。
5. **神识可扫察，藏身需手段。** 主角躲过高阶修士时，必须交代用了什么。
6. **功法有排他性。** 不能什么都会。修的功法路数应当限定他的战斗方式，也构成他的弱点。
7. **契约与道誓不可违。** 一旦立誓就必须有约束力，否则整套规则失效。
8. **凡人不可无视。** 修真界与凡俗的关系要有稳定设定（隔绝 / 统治 / 共存），不要时紧时松。

## 七、常见开局与各自的坑

| 开局 | 优势 | 坑 |
|---|---|---|
| 被逐出宗门 | 冲突与动力现成，天然的恩怨弧 | 太常见，需要在细节上给出独特性 |
| 灵根被废 / 资质低劣 | 打脸空间大，读者代入强 | 逆袭手段容易写成天降外挂，必须有代价 |
| 家族没落 | 责任感驱动，配角池现成 | 家族成员容易写成脸谱 |
| 意外获得传承 | 起步快 | 最容易失控——传承给的力量必须有使用门槛和代价 |
| 重生 / 前世记忆 | 信息差天然存在，读者爽感强 | 主角全知会导致悬念丧失，必须限制记忆的范围与可靠性 |

无论哪种开局，**第一章内必须让读者知道主角想要什么**，否则追读无从建立。
